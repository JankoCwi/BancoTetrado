# BancoTetrado

BancoTetrado is a Python tool for generating schematic two-dimensional representations of G-quadruplex structures from structural data produced by [ElTetrado](https://github.com/tzok/eltetrado).

The program generates diagrams based on the graphical representation proposed by Banco and Ferré-D'Amaré. It uses information contained in ElTetrado JSON output to reconstruct tetrads, G-tracts, strand connections and selected conformational properties of individual nucleotides.

BancoTetrado was developed as part of a master's thesis focused on the visualization and representation of G-quadruplex structures.

## Features

BancoTetrado visualizes information describing G-quadruplex topology, including:

* guanine tetrads and their arrangement,
* G-tracts,
* strand connectivity,
* loops and bulges,
* tetrad extensions involving additional nucleotides,
* glycosidic conformation,
* sugar-pucker information,
* strand orientation.

The resulting diagrams are saved as vector graphics in SVG format.

## Requirements

BancoTetrado requires:

| Component | Requirement    |
| --------- | -------------- |
| Python    | 3.8 or newer   |
| svgwrite  | 1.4.3 or newer |


## Installation

Clone the repository:

```bash
git clone https://github.com/JankoCwi/BancoTetrado.git
cd BancoTetrado
```

Install the package:

```bash
pip install .
```

After installation, the `bancotetrado` command becomes available from the command line.

## Input data

BancoTetrado uses JSON files generated by ElTetrado as its input.

The JSON file contains the structural annotation of a G-quadruplex, including information about tetrads, nucleotides, G-tracts, base pairs and nucleotide conformational properties.


## Usage

Basic usage:

```bash
bancotetrado -i INPUT.json -o OUTPUT
```

where:

`-i` specifies an ElTetrado JSON input file,

`-o` optionally specifies the output path or output file name.
